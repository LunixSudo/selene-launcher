Для игры нужна лицензия Minecraft: Java Edition: вы входите через аккаунт Microsoft, пиратского
режима нет.

> Ранняя разработка: релиза пока нет. Основная платформа Windows, сборки для Linux новые.

## Почему Selene

- Лаунчер бережёт слабые ПК. Память, Java и её флаги подбираются под ваши ОЗУ, процессор и
  моды, игра запускается на дискретной видеокарте, а лаунчер не мешает, пока вы играете.
  Стиль по умолчанию без размытия и бесконечных анимаций.
- Загрузки работают, даже когда сайты недоступны. Если не открываются Mojang, сайты
  загрузчиков, Modrinth или CurseForge, файлы берутся с их официальных зеркал, а потом с
  публичных, и всё равно сверяются с официальными контрольными суммами.
- Modrinth и CurseForge собраны в одном каталоге. Зависимости ставятся сами, а обновления
  модпаков не трогают то, что вы добавили сами.
- У лаунчера нет своих серверов, аналитики и рекламы.

## Возможности

### Аккаунты

- Вход через Microsoft с проверкой лицензии при каждом входе, несколько аккаунтов сразу.
- Новый аккаунт выбирает ник прямо в лаунчере; потом ник можно сменить, с проверкой, что он
  свободен, и с предупреждением о 30 днях до следующей смены.
- Одиночная игра без интернета для аккаунта, который уже входил.

### Игра

- Все версии от первых альф до свежих снапшотов, для каждой скачивается нужная Java.
- Fabric, Quilt, Forge (с 1.7.10) и NeoForge. Forge и NeoForge ставятся своим установщиком в
  фоне, без окон.
- Новая сборка сразу скачивает всё нужное, поэтому первый запуск быстрый, а установленная
  игра запускается без повторной проверки всех файлов.
- Автоматическая память: от 3 ГБ для ванили до 10 ГБ для больших сборок, не больше половины
  ОЗУ. Игры на Java 19 и новее сохраняют загруженные классы и в следующий раз запускаются
  быстрее.
- Запасные источники: официальные зеркала Mojang, Fabric и Forge, затем
  [BMCLAPI](https://bmclapidoc.bangbang93.com/). Java берётся ещё с Eclipse Temurin от
  [Adoptium](https://adoptium.net/) и с [Azul Zulu](https://www.azul.com/downloads/).

### Сборки

- Поиск, сортировка, группы, значки и обложки, копии и ярлыки на рабочем столе со значком
  самой сборки.
- Перенос сборки на другую версию игры с заменой модов на подходящие и выбор более новой или
  старой версии загрузчика.
- Подобранные аргументы Java или флаги из списка с поиском.
- Время в игре для каждой сборки и общее на главной.

### Дополнения и модпаки

- Моды, ресурспаки, шейдеры и датапаки с Modrinth и CurseForge в одной вкладке, с несколькими
  категориями сразу и автоматической установкой нужных зависимостей.
- Обновления в том же канале, из которого мод установлен, предупреждение перед включением
  мода для другой версии и пометка двух копий одного мода.
- На Forge OptiFine ставится с его официального сайта, открытого прямо в лаунчере.
- Модпаки по версии игры, в выбранной вами версии, с обновлением без потери ваших
  дополнений. Импорт и экспорт `.mrpack` и `.zip` CurseForge, в том числе перетаскиванием на
  окно.

### Игровой процесс

- Миры с переименованием и резервными копиями, серверы со входом в один клик и скриншоты.
- Консоль игры, разбор вылетов с советами и кнопка, которая закрывает зависшую игру.
- Статус в Discord, который можно выключить.

### Скины

- Анимированный 3D-просмотр, библиотека скинов и ряд плащей для примерки.

### Лаунчер

- Светлая и тёмная темы, стили Mica и стекло, живые фоны, анимации и звук нажатий по желанию,
  пиксельный шрифт в стиле Minecraft и свои наборы стиля.
- Русский и английский, плюс машинный перевод на украинский, немецкий, испанский,
  бразильский португальский, польский, турецкий и китайский; язык берётся из системы.
- Сохранение настроек в файл и загрузка их на другом ПК.
- Обновления с GitHub Releases с проверкой SHA-256 и «Сообщить о проблеме», которое само
  заполняет отчёт об ошибке.
- Портативный режим: пустой `portable.txt` рядом с программой хранит все данные рядом с ней.

## Требования

- Windows 10 или 11, 64-битная. Если нет Microsoft Edge WebView2, установщик добавит его.
- Или 64-битный Linux с WebKitGTK 4.1.
- Аккаунт Microsoft с купленной Minecraft: Java Edition. Java лаунчер скачает сам.

## Скачать

Официальные сборки есть только в этом репозитории. Сайт [selene.games](https://selene.games/ru/)
ссылается на те же файлы. Копии с других сайтов не наши и могут быть изменены.

Пока первый релиз не вышел на [GitHub Releases](https://github.com/LunixSudo/selene-launcher/releases),
тестовые сборки прикреплены к запускам процесса
[Build](https://github.com/LunixSudo/selene-launcher/actions/workflows/build.yml): установщик и
портативный `.zip` для Windows, AppImage и пакет `.deb` для Linux. Установщик для Windows пока
не подписан, поэтому SmartScreen может предупредить о нём. Сборки для Linux ещё мало
проверены и не обновляются сами.

К каждому релизу приложены контрольные суммы и подписанное подтверждение, что файлы собраны
здесь из отмеченного коммита. Как их проверить, написано в
[SECURITY.md](SECURITY.md#checking-a-download).

Данные лежат в `%APPDATA%\SeleneLauncher` в Windows и в `~/.local/share/SeleneLauncher` в Linux.

## Конфиденциальность

У лаунчера нет своих серверов, и он ничего не собирает. Токен входа хранится в защищённом
хранилище системы и передаётся только Microsoft и Mojang. В [PRIVACY.ru.md](PRIVACY.ru.md)
([in English](PRIVACY.md)) перечислены все сервисы, к которым подключается лаунчер, и зачем.
Установщик показывает политику на языке системы, а лаунчер спрашивает снова после обновления,
которое её меняет.

## Сборка из исходников

Нужны Rust (rustup сам поставит версию из `rust-toolchain.toml`), Node.js 26, pnpm 10 и
[зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для вашей системы.

```sh
pnpm install
pnpm tauri dev
```

Релизная сборка:

```sh
pnpm tauri build
```

Каталогу CurseForge при сборке нужен ключ API в переменной окружения `CURSEFORGE_API_KEY`.
Без него сборка ищет только на Modrinth.

`pnpm build` также записывает `static/third-party-licenses.txt` из `cargo metadata` и
установленных пакетов npm (лаунчер показывает его в «Настройки → Сторонние лицензии») и копии
политики конфиденциальности для установщика в `src-tauri/nsis/privacy`.

## Устройство проекта

- `crates/selene-core`: всё, что не требует окна: Mojang, вход Microsoft, Modrinth,
  CurseForge, сборки, моды, модпаки и запуск игры.
- `src-tauri`: само приложение. Команды Tauri, хранилище аккаунтов, Discord и установщик в
  `src-tauri/nsis`.
- `src`: интерфейс на SvelteKit и Svelte 5.
