Selene Launcher Privacy Policy

Effective November 10, 2026.

Selene Launcher is a free, open-source launcher for Minecraft: Java Edition. It has no servers of its own, so its developers never receive or store any data about you.

In short:

- The launcher never sees your Microsoft password.
- Everything it saves stays on your computer.
- It connects only to the services listed below, and only when a feature needs them.
- It collects no statistics or analytics, shows no ads, and does not sell or share data with anyone.

What stays on your computer

- You sign in on a Microsoft page. The token that signs you in again is kept in the system credential store (Credential Manager on Windows, the Secret Service keyring on Linux), not in a plain file. Your player name, UUID and skin are saved in the launcher folder so the launcher can list your accounts.
- Instances, worlds, mods, saved skins, screenshots, crash reports, play time and settings live in %APPDATA%\SeleneLauncher (on Linux ~/.local/share/SeleneLauncher), or next to the program in the portable version. With Java 19 and newer, each instance also gets a classes.jsa file that makes the next start faster. It holds only the code of the game and its mods.
- The launcher writes a log to logs\launcher.log. It records:
  - the launcher version and your system;
  - the models of your processor, graphics card, memory sticks and motherboard, never their serial numbers;
  - free disk space;
  - the Java arguments of each start and how long the game took to load;
  - which download sources answered and why some failed;
  - game starts, exits and errors;
  - the last lines the game printed before a crash.

  The log holds no passwords, tokens or keys, and the launcher never sends it anywhere by itself.
- The OptiFine window keeps the site's cookies and cache in %LOCALAPPDATA%\io.github.lunixsudo.selene, as any browser would.
- "Save to file" in the settings writes the look and launcher settings to a file you choose. That file holds no accounts, tokens or instances.

None of this leaves your computer, except as described below.

What the launcher connects to

- Microsoft and Xbox Live. Why: Signing in. Sent: Sign-in tokens.
- Mojang and Minecraft Services. Why: Checking you own the game, downloading the game and Java, skins and capes, creating and changing your player name. Sent: Your Minecraft token, the skin you choose, the player name you type.
- Fabric, Quilt, Forge and NeoForge. Why: Installing mod loaders: the list of builds and the loader files. Forge and NeoForge fetch theirs with their own installer. If a site is down, the same files come from the official mirrors the project lists (for Forge, CreeperHost). Libraries from other projects that the loaders need, such as ASM, come from Maven Central (repo1.maven.org) first. Sent: The game version.
- BMCLAPI (bmclapi2.bangbang93.com, run by bangbang93). Why: A spare copy of the game, Java and loader files, used only when the official servers and their mirrors cannot be reached. BMCLAPI serves each file from one of its download nodes, run by volunteers and Chinese university mirrors (CERNET), and those nodes see your IP address too. Files are checked against the official checksums whenever the launcher can get them. Sent: The address of the requested file.
- Adoptium (api.adoptium.net, run by the Eclipse Foundation), GitHub and the TUNA mirror (mirrors.tuna.tsinghua.edu.cn, Tsinghua University). Why: Eclipse Temurin Java, used only when Mojang's Java cannot be downloaded. The file is checked against Adoptium's SHA-256 checksum. Sent: The Java version, your system and processor type.
- Azul (api.azul.com, cdn.azul.com, Azul Systems). Why: Azul Zulu Java, used only when neither Mojang's Java nor Temurin can be downloaded. The file is checked against Azul's SHA-256 checksum. Sent: The Java version, your system and processor type.
- Modrinth and CurseForge. Why: The catalog, installing and updating mods and modpacks. Sent: Search queries, and checksums of installed files so the launcher can recognise them and find updates.
- MCIM (mod.mcimirror.top). Why: A spare copy of the Modrinth and CurseForge catalogs and mod files, used only when those sites cannot be reached. Mod files are checked against the catalog checksums, which also come from MCIM while the catalog is down. The launcher's CurseForge key is never sent there. Sent: Search queries, checksums of installed files.
- OptiFine (optifine.net). Why: The official OptiFine site, opened in a launcher window only when you press "Install OptiFine". Before that, the mods tab of a Forge instance reads the site's downloads page, at most once every 10 minutes, to check for a build for the game version that is not installed yet. The site and its ads work as in any browser. Sent: What any website sees: your IP address and what you click.
- GitHub. Why: Checking for and downloading launcher updates. You can turn this off in settings. Sent: Nothing beyond the request itself.
- Discord (the app on your computer). Why: The status in your Discord profile. If you turn it off in settings, the launcher does not connect to Discord at all. Sent: The instance name, the game and loader versions and when the game started, or "In the launcher".

Every request carries the launcher's name and version, as Modrinth asks of all apps. Like any website, these services see your IP address and handle data under their own policies. The launcher sends them only what a feature needs.

Project pages in the catalog show icons, descriptions and galleries picked by the project authors. Those images may be hosted on other sites, which then also see your IP address when you open the page.

If Windows does not have the Microsoft Edge WebView2 Runtime, the installer downloads it from Microsoft (go.microsoft.com), because the launcher window cannot run without it. Windows 11 already includes it.

Reporting a problem

"Report a problem" in the settings opens a new bug report on GitHub in your browser, already filled in with:

- what you wrote;
- the launcher version, your system and the models of your hardware;
- if you choose, the end of the launcher log, with your Windows user name hidden.

The whole log, with the user name hidden too, is saved to %TEMP%\SeleneLauncher\selene-report.log so you can attach it. Nothing is sent until you press the button on GitHub yourself. Reports on GitHub are public, so read the text before you send it.

The game itself

Minecraft is a Microsoft product. While you play, the game connects to Mojang and Microsoft and sends them its own data, telemetry included, under the Microsoft Privacy Statement (https://privacy.microsoft.com/privacystatement). Servers you join see your player name, skin and IP address, and mods work under the rules of their authors. The launcher has no say in any of this.

Security

- Sign-in tokens are kept only in the system credential store and never get into files or logs.
- Downloaded files are checked against the checksums their sources publish, and a file that does not match is thrown away.
- The source code is open: anyone can check what the launcher does.
- Please report a vulnerability privately, as described in the security policy (https://github.com/LunixSudo/selene-launcher/security/policy).

Deleting your data

- "Sign out" in the account menu removes that account's token from the credential store.
- When uninstalling, tick "Delete instances, worlds and launcher settings". This also removes the sign-in tokens of all accounts and the data of the OptiFine window.
- In the portable version, sign out of your accounts and delete the program folder.
- Data held by Microsoft and Mojang is deleted through their own services.

Children

The launcher collects no data about anyone, children included. Age rules for Microsoft accounts are set by Microsoft.

Changes and contact

When this policy changes, the launcher shows the new version on its next start. New versions are published in the project repository: https://github.com/LunixSudo/selene-launcher. You can ask questions there, under Issues.

Selene Launcher is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.
