Политика конфиденциальности Selene Launcher

Действует с 29 октября 2026 года.

Selene Launcher — бесплатный лаунчер Minecraft: Java Edition с открытым исходным кодом. У него нет своих серверов: разработчики не получают и не хранят никаких данных о вас.

Что хранится на вашем компьютере

- Вход в аккаунт. Вы входите через страницу Microsoft, лаунчер не видит ваш пароль. Токен для повторного входа хранится в защищённом хранилище Windows (Диспетчер учётных данных), а не в обычном файле. Ник, UUID и скин игрока сохраняются в папке лаунчера, чтобы показывать список аккаунтов.
- Игровые данные. Сборки, миры, моды, скины из библиотеки, логи, отчёты о вылетах и настройки лежат в %APPDATA%\SeleneLauncher или рядом с программой в портативной версии. Собственный журнал лаунчера, logs\launcher.log, записывает версию лаунчера, систему, модели процессора, видеокарты, планок памяти и материнской платы (без серийных номеров), свободное место на диске, аргументы Java при каждом запуске, какие источники загрузок ответили и почему некоторые не сработали, запуски и закрытия игры, ошибки и последние строки игры перед вылетом; в нём нет паролей, токенов и ключей. Он покидает твой ПК, только если ты сам приложишь его к отчёту об ошибке; «Сообщить о проблеме» в настройках перед этим скрывает в нём имя пользователя Windows.

Всё это никуда не отправляется, кроме случаев, описанных ниже.

Куда лаунчер подключается

- Microsoft и Xbox Live: вход в аккаунт. Передаётся: токены входа.
- Mojang и Minecraft Services: проверка лицензии, загрузка игры и Java, скины и плащи, создание и смена ника. Передаётся: токен Minecraft, выбранный скин, введённый ник.
- Fabric, Quilt, Forge и NeoForge: загрузчики модов, список версий и сам загрузчик, который Forge и NeoForge скачивают своим установщиком. Если сайт недоступен, те же файлы берутся с официальных зеркал, которые указывает сам проект, у Forge это CreeperHost. Библиотеки других проектов, которые нужны загрузчикам (например, ASM), сначала берутся с Maven Central (repo1.maven.org). Передаётся: версия игры.
- BMCLAPI (bmclapi2.bangbang93.com, автор bangbang93): запасная копия файлов игры, Java и загрузчиков. Используется, только когда официальные серверы и их зеркала недоступны. BMCLAPI отдаёт каждый файл с одного из своих узлов раздачи, которые держат добровольцы и зеркала китайских университетов (CERNET), поэтому они тоже видят ваш IP-адрес. Файлы сверяются с официальными контрольными суммами, когда их удаётся получить. Передаётся: адрес запрошенного файла.
- Adoptium (api.adoptium.net, Eclipse Foundation), GitHub и зеркало TUNA (mirrors.tuna.tsinghua.edu.cn, университет Цинхуа): Java Eclipse Temurin. Используется, только когда Java от Mojang не удаётся скачать. Файл сверяется с контрольной суммой SHA-256 от Adoptium. Передаётся: версия Java, тип системы и процессора.
- Azul (api.azul.com, cdn.azul.com, Azul Systems): Java Azul Zulu. Используется, только когда не удаётся скачать ни Java от Mojang, ни Temurin. Файл сверяется с контрольной суммой SHA-256 от Azul. Передаётся: версия Java, тип системы и процессора.
- MCIM (mod.mcimirror.top): запасная копия каталогов и файлов модов Modrinth и CurseForge. Используется, только когда эти сайты недоступны. Файлы модов сверяются с контрольными суммами из каталога (пока сам каталог недоступен, суммы тоже берутся из MCIM). Передаётся: поисковые запросы, контрольные суммы установленных файлов.
- Modrinth и CurseForge: каталог, установка и обновление модов. Передаётся: поисковые запросы, контрольные суммы установленных файлов, чтобы узнать их и найти обновления.
- OptiFine (optifine.net): официальный сайт OptiFine. Открывается в окне лаунчера, только когда вы нажимаете «Установить OptiFine». До этого вкладка модов сборки на Forge читает их страницу загрузок (не чаще раза в 10 минут), чтобы узнать, есть ли под версию игры сборка, которой ещё нет в модах. Передаётся: то же, что видит любой сайт, ваш IP-адрес и ваши нажатия.
- GitHub: проверка обновлений лаунчера. Передаётся: ничего, кроме обычного запроса.
- Discord (приложение на вашем компьютере): статус «Играет в Selene Launcher». Передаётся: версия игры и название сборки. Выключается в настройках.

Как и любой сайт, эти сервисы видят ваш IP-адрес и обрабатывают данные по своим правилам. Лаунчер не передаёт им ничего сверх нужного для работы функции.

На страницах проектов в каталоге показываются значки, описания и галереи, которые выбрали их авторы. Картинки могут лежать на других сайтах, и тогда эти сайты тоже видят ваш IP-адрес, когда страница открыта.

Лаунчер не собирает статистику и аналитику, не показывает рекламу и не продаёт и не передаёт данные третьим лицам.

Как удалить данные

- «Выйти» в меню аккаунта удаляет токен из хранилища Windows.
- При удалении программы можно отметить «Удалить сборки, миры и настройки лаунчера».
- Данные на стороне Microsoft и Mojang удаляются через их сервисы.

Дети

Лаунчер не собирает данных ни о ком, в том числе о детях. Правила возраста для аккаунта Microsoft задаёт Microsoft.

Изменения и связь

Новая версия политики публикуется в репозитории проекта: https://github.com/LunixSudo/selene-launcher. Вопросы можно задать там же, в разделе Issues.

Selene Launcher — неофициальный продукт, он не связан с Mojang и Microsoft и не одобрен ими.
