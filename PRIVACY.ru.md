# Политика конфиденциальности Selene Launcher

Действует с 28 октября 2026 года.

Selene Launcher — бесплатный лаунчер Minecraft: Java Edition с открытым исходным кодом. У него нет своих серверов: разработчики не получают и не хранят никаких данных о вас.

## Что хранится на вашем компьютере

- **Вход в аккаунт.** Вы входите через страницу Microsoft, лаунчер не видит ваш пароль. Токен для повторного входа хранится в защищённом хранилище Windows (Диспетчер учётных данных), а не в обычном файле. Ник, UUID и скин игрока сохраняются в папке лаунчера, чтобы показывать список аккаунтов.
- **Игровые данные.** Сборки, миры, моды, скины из библиотеки, логи, отчёты о вылетах и настройки лежат в `%APPDATA%\io.github.lunixsudo.selene` или рядом с программой в портативной версии.

Всё это никуда не отправляется, кроме случаев, описанных ниже.

## Куда лаунчер подключается

| Сервис | Зачем | Что передаётся |
| --- | --- | --- |
| Microsoft и Xbox Live | Вход в аккаунт | Токены входа |
| Mojang и Minecraft Services | Проверка лицензии, загрузка игры и Java, скины и плащи | Токен Minecraft, выбранный скин |
| Fabric, Quilt, Forge и NeoForge | Загрузчики модов: список версий и сам загрузчик, который Forge и NeoForge скачивают своим установщиком | Версия игры |
| Modrinth и CurseForge | Каталог, установка и обновление модов | Поисковые запросы, контрольные суммы установленных файлов, чтобы узнать их и найти обновления |
| GitHub | Проверка обновлений лаунчера | Ничего, кроме обычного запроса |
| Discord (приложение на вашем компьютере) | Статус «Играет в Selene Launcher» | Версия игры и название сборки. Выключается в настройках |

Как и любой сайт, эти сервисы видят ваш IP-адрес и обрабатывают данные по своим правилам. Лаунчер не передаёт им ничего сверх нужного для работы функции.

Лаунчер не собирает статистику и аналитику, не показывает рекламу и не продаёт и не передаёт данные третьим лицам.

## Как удалить данные

- «Выйти» в меню аккаунта удаляет токен из хранилища Windows.
- При удалении программы можно отметить «Удалить сборки, миры и настройки лаунчера».
- Данные на стороне Microsoft и Mojang удаляются через их сервисы.

## Дети

Лаунчер не собирает данных ни о ком, в том числе о детях. Правила возраста для аккаунта Microsoft задаёт Microsoft.

## Изменения и связь

Новая версия политики публикуется в репозитории проекта: https://github.com/LunixSudo/selene-launcher. Вопросы можно задать там же, в разделе Issues.

Selene Launcher — неофициальный продукт, он не связан с Mojang и Microsoft и не одобрен ими.
